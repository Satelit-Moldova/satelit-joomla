# Changelog

## 1.0.0 (2026-11-19)

- First release: `pkg_satelit` with the Satelit library, the module `mod_satelit` (BNM rates, fuel prices, latest news, cinema today, joke of the day, new laws) and the plugin `plg_content_satelit` (`{satelit ...}` tags, API key).
- One package for Joomla 3.10, 4.x and 5.x.
- Languages: en-GB, ro-RO, ru-RU.
